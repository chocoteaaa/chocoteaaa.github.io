butterfly主题部署心得

发表于2026-08-26|更新于2026-08-28
|总字数:1982|阅读时长:9 分钟|浏览量:

记得刚开始学web时候看到学长的博客，暖色调十分唯美，还有动态打字效果，太酷了，被学长带着部署了一个hexo+github的博客，一开始简简单单选的cactus（仙人掌）主题，说是简洁高端大气上档次，但是自己还是想做一个像他们一样的页面。

现在把这个博客主题换了一下，github上也改了下，用了butterfly这个主题，改了半天终于差不多了，记录一下自己怎么搞的，忘了也看得懂，基础部署就不说了，主要是在butterfly主题的config.yml文件里操作。

Menu

菜单，这里面没啥好说的，注意格式就行了，就主页有什么东西能点

Code blocks

代码块，终于知道那些好看的苹果风格代码块怎么来的了！

Image Settings

最喜欢的图片部分，可自行下载。这里 transparent 可以理解为透明状态（找了半天才知道有这个），我的配置透明了一些部分，这样就只有头像、标签小图、和一个大背景图。

PS：可以去在线工具把图片裁成圆形等各种形状！

Subtitle

副标题，主标题下面，可以开打字效果的那个，位于150行左右

Announcement

公告（全局config里语言设置为中文才知道这是公告），在Aside Settings里，位于300行左右

Global font settings

全局字体设置，归属于Beautify / Effect 美化与特效 这个板块，其中还有很多如主题按钮等元素的颜色大小之类的更改，这里主要改字大小，字小太恶心了，必须改啊！我用的是16.5px大小，默认14px。

Background effects

背景效果，这个还是很好玩的，R(红)、G(绿)、B(蓝)就是屏幕的光学三原色，850行左右

inject

inject 是butterfly里非常重要的代码注入功能，不用修改主题原始文件，把自定义 CSS、JS、HTML 插入网页里，升级主题的时候你的修改不会丢失，写的时候注意格式。

下面是我用的，主要功能是给卡片加上透明模糊效果（有其它效果可见：hexo 博客自定义美化配置 — butterfly 主题）。但透明度太低会看不清文字，于是下方加入了让文字强制保持颜色的功能。

还有一些search什么的设置就不写出来了，反正config.yml文件里面有什么不懂的，问豆包就行了。
