序列化与反序列化

基础概述

在 PHP 中，变量、数组、对象是驻留在内存中的数据结构，内存数据在脚本执行结束后会自动销毁，无法直接持久化存储或者跨请求传输。 序列化（serialize）与反序列化（unserialize）就是 PHP 提供的一套数据持久化方案：

  • 序列化：将内存中的复合数据（数组、对象等）转换成一段具有固定格式的字符串，这个字符串保留数据的类型、值、对象类名、属性信息，可以存入文件、缓存、数据库、Cookie。
  • 反序列化：读取序列化字符串，按照格式解析，在内存中重新还原成原来的 PHP 变量、对象实例。

前提：序列化只能保存数据（属性），不能保存方法代码。反序列化还原对象时，要求当前运行环境中已经加载该对象对应的类定义，否则得到的是 __PHP_Incomplete_Class 不完整类对象，无法调用类内方法。

函数原型

支持序列化的数据类型：string、int、float、bool、null、array、object
不支持序列化：资源类型（resource，数据库连接、文件句柄、socket 句柄等），资源无法被打包成字符串。

序列化字符串格式解析

php序列化的存储格式是json，举个例子，一个类有三个属性。

  • O:2:"me":3:{ ... }表示这个是一个对象且类名为me
    • O = Object 对象
    • 2 = 类名 me 长度是 2
    • "me" = 类名
    • 3表示该类有三个属性
    • 大括号内部是 3 个属性，按访问修饰符区分
  • s:4:"name";s:3:"jun";
    • 第一个属性值为字符串，属性名为name（（public重在属性））
    • 属性内容为jun，字符串长度 4
  • s:7:"\0me\0age";s:3:"100";
    • private 属性固定格式：\0类名\0属性名
    • \0 是空字节（chr(0)，不是 \ + 0 两个字符）
    • 拼接后：\0me\0age（（private重在类名））
    • 字符个数：空字节 (1)+m+e + 空字节 (1)+a+g+e → 一共 7 个，所以s:7
      • 注意：私有属性必须写定义它的类名，这里类名是 me，不是别的
  • s:11:"\0*\0language";s:2:"CN";
    • protected 属性固定格式：\0*\0属性名
      • \0 空字节、* 是固定占位符
      • 拼接：\0*\0language
      • 长度：空 (1)+*(1)+ 空 (1)+l+a+n+g+u+a+g+e → 一共 11 个，所以s:11
