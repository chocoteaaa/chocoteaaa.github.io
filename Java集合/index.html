前情

集合，是由若干确定元素组成的整体。在计算机中引入集合，是为了方便批量处理一组同类型数据，比如：

  • 统计全班同学的总分与平均分；
  • 展示所有商品的名称与售价；
  • ……

在 Java 里，如果一个对象能够内部存放多个其他对象，并且对外提供访问这些元素的接口，我们就称它为集合。数组本质上也可以看作一种集合：

既然已经有数组可以承载一组数据，为什么 Java 还要提供专门的集合类？因为数组本身存在明显局限：

  • 数组一经初始化，长度固定，无法动态扩容缩容；
  • 大多只能依靠下标按顺序访问元素，缺少灵活的查询、去重等能力。

所以 Java 提供了多种多样的集合类，适配不同业务场景：

  • 支持动态扩容的顺序链表；
  • 自动
  • ……

Collection

Java 标准库在 java.util 包中提供了集合根接口 Collection，它是除 Map 以外所有集合类的父接口。

java.util 包主要分为三大类集合：

  • List：有序列表集合，可以通过索引访问元素，比如存放学生信息、按序号排列的学生列表；
  • Set：元素不可重复的集合，适合去重场景，比如存放不重名的学生；
  • Map：键值对（key-value）映射集合，通过 key 查询 value，例如根据学生姓名查找对应的学生对象。

Java 集合框架有几个核心设计特点：

  1. 接口与实现分离：以 List 接口为例，它定义有序列表的行为，而 ArrayList、LinkedList 是它不同的实现类，底层结构和性能各不相同；
  2. 支持泛型：可以约束集合内元素类型，避免类型混乱，示例：
  1. 统一迭代方式：使用迭代器 Iterator 遍历集合，使用者不需要关心集合底层的存储结构。

历史遗留类 / 接口，新项目不推荐使用：

  • 遗留类：Hashtable（Map）、Vector（List）、Stack（栈）
  • 遗留接口：Enumeration，功能已经被 Iterator 替代

Iterator迭代器接口

特点：

  • Iterator 对象成为迭代器（设计模式的一种），主要用于遍历Collection集合中的元素
  • Collection 接口继承了 java.lang.Iteratheor 接口，该接口有一个 iterator() 方法，那么所有实现了 Collection 接口的集合类都有一个 iterator() 方法，用于返回一个实现了 Iterator 接口的对象。
  • Iterator仅用于遍历集合，Iterator 本身并不提供橙装对象的能力，所以当我们想创建一个 Iterator 对象时，则必须有一个被迭代的集合。
  • 集合对象每次调用 iterator() 方法都得到一个全新的迭代器对象，默认游标都在集合的第一个元素之前。

核心思想：将集合遍历行为和集合本身解耦，不用关心底层是数组、链表、哈希表，统一一套遍历 API。

Collection子接口—List接口

特点

  • 鉴于Java中数组用来存储数据的局限性，我们通常使用List替代数组
  • List集合类中元素有序，且可重复，集合中的每个元素都有其对应的顺序索引
  • List容器中的元素都对应一个整数型的序号记载其在容器中的位置，可以根据序号存取容器中的元素
  • JDK API中List接口的实现类有：ArrayList、LinkedList和Vector

List接口常用实现类的对比

  • List：元素有序，可重复的集合 –> 动态数组
  • ArrayList：作为List接口的主要实现类；线程不安全的，效率高；底层使用Object[] elementData存储
  • LinkedList：对于频繁的插入、删除操作，使用此类效率比ArrayList高；底层使用双向链表存储
  • Vector：作为List接口的古老实现类；线程安全的，效率低；底层使用Object[] elementData存储

Collection子接口—set接口

特点

  • Set接口是Collection的子接口，set接口没有提供额外的方法
  • Set 集合不允许包含相同的元素，如果试把两个相同的元素加入同一个Set 集合中，则添加操作失败。
  • Set 判断两个对象是否相同不是使用==运算符，而是根据equals()方法

Set 三个实现类对比

  • Set：元素无序，不可重复的集合 –> 高中数学讲的集合
  • HashSet：作为Set接口的主要实现类；线程不安全的；可以存储null值
    • LinkedHashSet：作为HashSet的子类；遍历其内部数据时，可以按照添加的顺序遍历，对于频繁的遍历操作，LinkedHashSet效率高于HashSet.
  • TreeSet：可以按照添加对象的指定属性，进行排序。
实现类 底层 特点
HashSet 哈希表（数组 + 链表 + 红黑树 JDK8） 无序、不可重复；线程不安全；允许存 null；查询快
LinkedHashSet HashSet 子类，哈希表 + 双向链表 保留插入顺序；不可重复；遍历效率高于 HashSet

添加元素完整流程

添加元素 a：

1、调用a.hashCode()计算哈希值，算出底层数组存放索引

2、判断数组索引位置有没有元素：

  • 位置为空：元素 a 直接存入（情况 1）

  • 位置已有元素 b：比较两者 hash 值

    • hash 值不同：a 存入，和 b 形成链表（情况 2）

    • hash 值相同：调用a.equals(b)

      • equals=true：判定重复，添加失败
      • equals=false：添加成功，形成链表（情况 3）

JDK7：新元素放在数组，指向旧元素（头插） JDK8：旧元素留在数组，新元素挂在链表尾部（尾插）

重点：自定义类存入 HashSet，必须重写hashCode()与equals() 不重写时使用 Object 原生方法，根据对象地址判断，两个 new Person (“Tom”,12) 地址不同，会都存入集合。

Collection子接口—Queue接口

特点

  • java.util.Queue 是 Collection 的子接口，和 List、Set 平级。
  • Queue：队列，先进先出 FIFO（大部分实现），用来存放等待处理的元素。
  • 特例：PriorityQueue 优先队列，不遵守 FIFO，按优先级出队。
  • Queue 继承 Collection，所以 Collection 的通用方法（add、remove、contains、iterator）Queue 全都能用。

CC1 在 JDK8u71 之后被修复（AnnotationInvocationHandler 不能再触发 setValue），于是 CC2/CC4 换了集合：PriorityQueue 优先队列。

Deque：Queue 的子接口（双端队列 Double Ended Queue）

Deque extends Queue 可以两端添加、两端取出，既可以当队列，也可以当栈。

  • 当队列（FIFO）：offerLast() 入队，pollFirst()出队
  • 当栈（LIFO 后进先出）：push()压栈，pop()弹栈

推荐：ArrayDeque 是 Deque 的实现类，性能优于 LinkedList，用来做队列、栈首选。 不推荐用古老的 Stack 类（线程安全、性能差，已过时）。

MAP

我们知道，List是一种顺序列表，如果有一个存储学生Student实例的List，要在List中根据name查找某个指定的Student的分数，应该怎么办？最简单的方法是遍历List并判断name是否相等，然后返回指定元素，

这种需求其实非常常见，即通过一个键去查询对应的值。使用List来实现存在效率非常低的问题，因为平均需要扫描一半的元素才能确定，而Map这种键值（key-value）映射表的数据结构，作用就是能高效通过key快速查找value（元素）。

Map 概述：java.util.Map，双列集合，和 Collection 是平级关系，Collection 是单列集合（一次存一个元素），Map 一次存一对（key+value）。

特点：
1、key 唯一，不可重复；value 可重复
2、一个 key 只能对应一个 value；重复 put 同一个 key，新 value 覆盖旧 value
3、key 可以为 null（HashMap 最多允许一个 null 的 key）；value 可以多个 null
4、Map 没有继承 Collection 接口，没有 iterator () 迭代器方法

使用须知

HashMap 添加元素原理

put (key,value) 流程：

  1. 计算 key 的 hash 值，算出数组下标
  2. 判断下标位置是否为空，为空直接放入
  3. 不为空，比较 hash 值：
    • hash 不同：挂链表
    • hash 相同，调用 equals 比较 key
      • equals=true：覆盖旧 value
      • equals=false：挂链表，链表 > 8 转红黑树

对比：

集合 底层 顺序 key 是否允许 null 线程安全
HashMap 数组 + 链表 + 红黑树 无序 ✅一个 null ❌不安全
LinkedHashMap 哈希表 + 双向链表 插入有序 ✅一个 null ❌不安全
TreeMap 红黑树 key 排序 ❌不允许 null ❌不安全
Hashtable 数组 + 链表 无序 ❌ ✅安全

使用场景选择

1、绝大多数场景，不需要顺序：HashMap
2、需要保留插入顺序：LinkedHashMap
3、需要 key 自动排序：TreeMap

集合在 Java 反序列化 / CC 链中的作用

CC 链（CommonsCollections）核心：利用集合类的 readObject() 在反序列化时自动执行内部方法，作为链入口，层层调用最终触发 Transformer.transform()，实现反射 RCE。

HashMap / HashSet / LazyMap / TransformedMap / PriorityQueue 都是 CC 链里高频出场的集合

Java 集合（Map/Set/Queue）**重写了 readObject()。反序列化的时候，集合在恢复内部元素的过程中，自动调用 hashCode() / put() / get() / compare()**。攻击者把恶意对象放进集合，反序列化重建集合时，自动触发方法调用，打通利用链。

CC1 用到的集合：TransformedMap

此物为 cc（commons-collections）自定义 Map 装饰器，是 CC1 的核心集合载体（装饰器包装原生 HashMap）。

  • 底层：包装普通HashMap，装饰模式，重写了 Entry 的setValue()
  • 关键逻辑：checkSetValue() 会执行 valueTransformer.transform()
  • CC1 完整调用链：

集合在这里作用：TransformedMap 的 Entry.setValue 是触发 transform 的开关。AnnotationInvocationHandler 反序列化读取成员时，触发 map entry 的 setValue。

配套还有 LazyMap（CC1 另一条分支）：LazyMap.get(key)，当 key 不存在，会调用factory.transform()，也是装饰 Map。

CC6 用到的集合：HashMap / HashSet

CC6 用来绕过 JDK8u71 修复的 AnnotationInvocationHandler。 用到两个核心：LazyMap + TiedMapEntry + HashMap/HashSet

集合的作用：

  • HashSet底层就是HashMap，HashSet.readObject()反序列化重建元素时执行`put()``
  • put过程计算 hash，调用元素hashCode()
  • 我们放入集合的元素是TiedMapEntry，它的hashCode()内部调用getValue()，进而触发LazyMap.get()。

关键点：**HashMap/HashSet 在反序列化重建的时候，会主动调用元素的 hashCode ()**，这就是入口。

CC 其他链里的集合

  • PriorityQueue（优先队列，属于 Queue）：CC2 / CB 链常用入口 PriorityQueue 重写readObject()，反序列化后自动执行 siftDown 排序，排序会调用compare()方法。 把恶意比较器放入 PriorityQueue，反序列化重建队列、排序时触发 compare，打通链条。

    Queue 在这里的作用：readObject 重建集合元素后自动排序，调用 compare 方法。

  • Hashtable：CC7，类似 HashMap，readObject 时 put 元素触发 hashCode

CC 链里两类集合区分

Commons-collections 自定义 Map 装饰集合（LazyMap、TransformedMap）【触发点】

不是 JDK 原生集合，是 CC 库自己写的 Map 包装类。

  • TransformedMap：entry.setValue() → transform
  • LazyMap：get () 找不到 key → factory.transform ()

这两个才是真正调用 transform 的核心，是链中间桥梁。

JDK 原生集合（HashMap、HashSet、PriorityQueue）【入口载体】

原生 JDK 集合，实现Serializable，重写readObject()。 作用：反序列化的时候，自动调用元素的 hashCode /compare，用来启动整条链。

原生集合本身没有漏洞，只是反序列化重建内部结构时会自动执行一些方法，被攻击者当做 gadget 入口。
